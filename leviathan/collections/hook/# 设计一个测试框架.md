# 编写一份搜索树的测试用例

我编写了几种二叉树，现在我需要编写一些测试用例。


## 树

- AVLTree
- RedBlackTree
- Treap


## 编程语言

C++26 | GCC16.2

你需要测试的函数如下：

## 测试函数

```cpp
// 侵入式链表参数为引用
std::pair<iterator, bool> insert(reference&);

template <typename K>
iterator find(const K& value);

constexpr iterator erase(const_iterator pos);

```
这是三个核心的函数，对于任何返回值不是 `void` 的函数，你至少应该有一组测试用例包含返回值的测试

## 节点设计

你可以假设树的类型为 `Tree`, 这样我们可以通过不同的二叉树类型来复用代码。

```cpp

// Tree 代表数的类型

// Checker 用于检测树是否满足要求，对于AVLTree，
// 我们会检查高度，对于RedBlackTree会检查颜色
// 调用方式如下 checker(tree)

template <typename Tree, typename Checker>
void SomeTestName(Tree tree, Checker checker);

```

我们测试的是侵入式容器，每一个节点的类型如下，你可以自由发挥，我们提供一个框架。

```cpp

// 我们的东西都位于这个名称空间下
using namespace cpp::collections::intrusive;

class TestNode
{
    // 一个作为Key的字段，随你发挥
    int Id;  
    
    // 一个作为Value的字段，随你发挥
    SomeOtherData some_other_data;    

    // 这是C++26的annotation，你可以假设这个代码是框架利用
    // 反射搜索字段的标识，对于每一种hook,你必须保证tag里面的
    // 字符串是不一样的。
    [[=cpp::refl::tag("hook")]]
    avl_hook hook;
};
```
Hook 种类:

- avl_hook
- red_black_hook
- treap_hook

每一种hook对应相应的Tree


## 搜索树

```
template <
    std::meta::info MemberHook, 
    typename KeyOfValue, 
    typename Compare = std::less<>, 
    bool UniqueKey = true
>
class tree;
```

结构如下：

- MemberHook 传入不同的 `Hook` 可以得到不同的树
- KeyOfValue 拿到节点的 `Key` 字段用于比较
- Compare 用于比较两个 `Key`
- UniqueKey 是否允许 `Key` 重复，这里你无需修改，只考虑唯一 `Key`

```cpp
struct IdProj
{
    int operator()(const TestNode node)
    {
        return node.Id;
    }
};

using RedBlackTree = tree<cpp::refl::search_tag(^^TestNode, "hook"), IdProj>;
```

我给出一个树的声明，你可以用于参考，以便于更好的了解如何配置模板参数。你可以自由发挥，无需严格按照例子来。

## 测试框架

Catch2 你可以直接使用

```cpp
#include <catch2/catch_all.hpp>
```
来引入你需要的全部测试组件，我们使用 `CHECK` 而非 `REQUIRE` 来避免程序遇到错误的测试用例直接提前结束。

对于其他头文件，你只需要列出STL的部分即可，至于Tree以及相关组件具体位于哪个头文件，你无需关心，我们后续会自行补上。

## 测试数据要求

- 你的数据用例需要包含常见的类型，比如红黑树插入的所有情况。

- 你的测试数据要包含大量随机数据，你可以采用random之类的随机数生成器来生成，不要硬编码。
